# Frame 转图片 PPT

在 Figma Design 中选中已编号的 Frame，运行插件即可生成 PowerPoint。每个 Frame 渲染为一张 JPG，再按编号放入独立幻灯片。转换在本地完成。

## 安装

下载并解压本仓库，在 Figma 桌面版的设计文件中打开 **插件 → 开发 → Import plugin from manifest…**，选择仓库根目录的 `manifest.json`。保留解压后的目录，供 Figma 读取插件文件。

## 使用

1. 选中需要导出的 Frame。名称可以是 `01 封面`、`02 调研`、`10 总结`。
2. 打开 **插件 → 开发 → Frame 转图片 PPT**，选择 **1×、2×、3× 或 4× JPG 转 PPT**。
3. 选择保存位置。若下载未自动开始，在插件窗口点击 **保存 PPTX**。

插件取每个 Frame 名称中的第一段数字，按数值升序排列。相同编号按画布位置从上到下、同高从左到右排列。编号可以跳号。选中的 Frame 如有缺少编号的，插件会提示其名称。

幻灯片比例跟随排序后的第一页。其他比例的图片等比居中，空白处为白色。倍率作用于 JPG 的宽和高。例如 1920 × 1080 的 Frame 选择 3× 时，目标图片尺寸为 5760 × 3240。输出文件名带有倍率。较高倍率需要更多内存，若 Figma 导出失败，可以选择较低倍率重试。文字和页眉包含在 JPG 中，修改文字时可回到 Figma 调整并重新导出。

## 文件

- `code.js` 读取选区，排序并通过 Figma 导出 JPG。
- `ui.html` 包含导出界面和本地 PowerPoint 生成库，可直接随插件运行。
- `LICENSE-pptxgenjs.txt` 为随附 PptxGenJS 的许可证。
